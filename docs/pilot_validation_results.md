# Pilot Validation 实验记录

## 1. 实验范围

本次 pilot 使用 Qwen3-8B 的本地 4-bit 量化模型，通过 LoRA 学习单轮工具选择、参数生成，以及需要澄清或不支持操作时的动作判断。

模型输出自定义 JSON。本次实验不连接业务数据库、不执行真实工具，也不评估多轮 Agent。

- Train：56 条，用于梯度更新。
- Validation：54 条，用于比较基线与不同训练 checkpoint。
- Validation 动作分布：call 30 条、clarify 15 条、unsupported 9 条。
- 本阶段未使用 Test。

这些数据由人工模板与参数组合生成。当前结果属于小规模预实验，不代表真实业务请求上的整体表现。

## 2. 训练与生成设置

训练运行：`run_20261015T102918_633822Z`。

- LoRA：最后 16 层，rank=8，scale=20，dropout=0。
- 学习率：1e-5；batch size：1；梯度累积：1；seed：42。
- 训练：3 个 epoch，共 168 次更新，每 56 步保存一次 checkpoint。
- 最大训练序列长度：2048；启用梯度检查点。
- 关闭 thinking，屏蔽 prompt 的训练损失。
- 训练过程中未使用 Validation 做梯度更新或计算验证损失。

四组 Validation 推理采用相同设置：关闭 thinking、temperature=0、max_tokens=256。

## 3. 指标口径

“全部自动检查通过”要求：

1. 输出能够严格解析为 JSON 对象。
2. 输出满足工具接口与动作结构约束。
3. action 与参考答案一致。
4. 参考答案为 call 时，工具名称和全部参数也必须完整匹配。

对于 clarify 和 unsupported，自动检查不判断说明文字的语义质量，该部分需要人工核对。

两个调用指标使用不同分母：

- 参考 call 样本的完整调用匹配率：完整正确调用数 / 应调用样本数。
- 已解析为 call 的输出中，完整调用正确率：完整正确调用数 / 模型预测为 call 的样本数。

第二个指标不包含模型误判为 clarify 或 unsupported 的应调用请求，因此需要结合其他指标判断。

## 5. Checkpoint 选择与错误分析

当前选择 step 56 作为 pilot 候选 checkpoint，因为其全部自动检查通过率在本次比较的四组方案中最高。

对应权重：`adapters/pilot/run_20261015T102918_633822Z/0000056_adapters.safetensors`。

与基线相比，step 56 修复了 10 条自动检查失败样本，未出现新增的自动检查失败样本。

step 112 和 step 168 分别将 9 条和 18 条应调用请求错误地判为 clarify，体现出不必要的澄清问题。当前观察不能单独证明性能下降的具体训练原因。

step 56 仍有以下问题：

- 整数阈值约束：用户输入 2.5 时，模型擅自改成 2 并生成调用，正确行为应是请用户确认正整数阈值。
- 澄清文字质量：食品分类请求虽然被判为 clarify，但模型没有明确说明目前支持的分类，文字可能造成误解。

因此，53/54 是自动检查通过数，不能直接解释为人工确认的业务成功数。

## 6. Step 56 人工语义审查

本次在导师指导下，对 step 56 的参考 clarify／unsupported 样本逐条开展语义审查，判断说明是否准确指出问题、明确需要补充的信息或不支持的操作，以及是否编造事实或工具能力。

审查记录保存在 `results/validation/message_review_step56.json`。原始模型输出保留，改写建议单独记录。

| 审查状态 | 数量 |
| --- | ---: |
| pass | 22 |
| needs_improvement | 1 |
| not_applicable | 1 |
| pending | 0 |

24 条参考非调用样本中，23 条具备可审查的说明文字，其中 22 条通过，语义通过率为 22/23（95.65%）。

阈值 2.5 样本被错误预测为 call，没有对应的澄清说明，因此不纳入说明文字审查分母；该样本仍保留为自动检查失败。

食品分类样本的 action 正确，但说明未明确支持的分类，判为 needs_improvement。人工改写建议不替换模型当时的输出。

结合自动检查，30 条正确调用与 22 条通过语义审查的非调用说明，共计 52/54（96.30%）通过本轮合并检查。评估对象仍是调用决定与说明文字。

本轮人工语义审查仅覆盖 step 56。四组方案的横向比较继续沿用第 4 节的自动指标，本节人工结果单独报告。

## 7. 结论边界

step 56 是当前 pilot 范围内的候选，不是已通过最终 Test 的方案。

本次比较仅包含一个训练 seed，数据规模较小，尚未开展统计显著性验证。模板与参数隔离也不等于已经证明对所有新语义表达的泛化能力。
